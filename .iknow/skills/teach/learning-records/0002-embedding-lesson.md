# 学习记录 · 第二课 Embedding 原理

## 用户反馈驱动的 ZPD 调整

- 用户在第一课（体系解构）后反馈：知识"只表面看了一下，不理解原理"。
- 决策：暂缓写代码（原计划的"手搭最简 RAG CLI"），转向**原理系列**打地基。
- 优先级：Embedding > Chunking > 检索/重排。理由是 Embedding 决定"相似"的数学标准，不懂它后面"为什么混合检索/重排有效"都讲不深。

## 本课核心概念（用户应已建立第一手理解）

1. 文字 → 高维坐标（embedding 模型决定"相似"空间的定义）。
2. 余弦相似度 = 方向一致性，cos≈1 相似 / ≈0 无关 / <0 相反。
3. RAG 召回的本质 = 求查询向量与文档向量的余弦相似度，取 top-K。

## 可复用组件

- 新建 `assets/cosine-sim.js`：2D 向量拖拽 + 余弦相似度实时显示，用于 embedding / 重排 / 混合检索等需要"向量相似性直觉"的课。
