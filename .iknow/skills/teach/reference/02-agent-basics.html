AI Agent 基础概念

Agent = 能感知环境、自主规划并执行动作以达成目标的系统。与单纯 LLM 调用的区别：Agent 具备规划(Planning)→行动(Action)→观察(Observation)的闭环 [原文 P10]。

核心循环

  • Planning：将目标拆解为子任务 [原文 P10]
  • Action：调用工具/API/代码执行 [原文 P10]
  • Observation：获取执行结果，反馈给下一轮规划 [原文 P10]
