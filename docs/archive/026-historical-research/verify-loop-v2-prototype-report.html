04关键场景结果（节选）

场景 2 — best-of-3 首轮失败后重跑

配置 candidateCount=3 + 候选序列 [1,1,0, 0,0,0]。

  • 第 1 轮：3 候选 2f1p → passRatio = 2/3 未达多数 → verdict=fail → 注入多候选失败信封（command + consensus + fail signatures + output_excerpt）。
  • 第 2 轮：3 候选全 pass → consensus=pass → 放行 → passed。
  • 实测：records.length=2，outcome=passed，rounds=2。失败信封中 output_excerpt 字段在第 1 轮已被追加（Spec 审查 #7 修复项生效）。

场景 6 — multi-judge 全 abstain（关键 fail-open 验证）

判官 "aaa"（transport 全部失败 → 三判官全 abstain）。

  • 关键行为：poolResult.verdict === "abstained" → outcome=unstable。不静默放行 — 这是 v2 相对 v1 的关键安全语义。
  • 实测：poolResult.agreement = 0，judgeVerdict = "abstained"，outcome=unstable，rounds=1，enabled=true（不是 disabled）。

场景 8 — 透明关闭（向后兼容）

command 空 + 无 runClassifier。

  • 关键行为：rounds=0，enabled=false，outcome=disabled。v1 SC7 向后兼容路径生效。
  • 实测：records.length=0，无 trace 记录，enabled=false。本次新增 disabled rounds=0 用例即为此行为锁定。

06原型简化与已知局限

原型主动简化 5 处，全部在头注释 + 行内注释披露，不假装生产就绪。

简化 原型做法 生产目标（留待 lift）
best-of-N 候选来源 对同一 command 做 K 次验证采样（验证层 best-of-N） 模型侧产 K 个候选修复再统一验证（模型侧候选采样）
position-bias shuffle 仅影响判官判定展示顺序（观测） 逐判官差异化输入 / 模型以做真实缓解
dispersion 早停 计算并记录进 record，不参与 stop 判定 dispersion 驱动的早停 / 加采样（shouldSampleMore）
escalate 通道 escalated outcome 保留 union 成员，不产出（无趋势裁判、无信封注入） 趋势裁判 + escalate 信封注入闭环
command 路径二值归一化 timeout 折叠为 fail 候选，与 exitCode != 0 同路 独立 unstable 通道以承载 v1 B13 语义

07后续 lift 步骤

原型通过后，进入生产 lift 的最小路径（不引入新依赖，按 v1 seam 渐进替换）。

  1. 生产化 effort budget 数字

    把 verify-loop-v2.ts 中的 spendEffort({tokens:200, costUsd:0.001, wallMs:1000}) 估算占位替换为 RunResult.usage 实测：每 round 后从 current.result.usage 取增量，累加进 effort.tokens / costUsd。wallMs 来自 Date.now() 差值。

  2. 接入 parseClassifierResult

    把判官 envelope 的字符串 contains 判断（'"kind":"pass"' / '"kind":"fail"'）替换为结构化 parseClassifierResult(envelope.result) — 对齐 v1 classifier 路径契约。

  3. 恢复 bwrap 沙箱真实路径 e2e

    在 bwrap 可用环境（CI runner / Linux dev box）跑 verify-loop-v2-e2e.test.ts 第 4 用例：makeDefaultRunVerify 真实路径，无 stub 替身。

  4. 补真实模型 e2e

    沿用主路径约定，把原型 ≥1 多 turn + ≥1 真实 tool_call 落到 archive/tests-real-llm/verify-loop-v2.test.ts（默认 vitest 不收集），npm run test:real-llm 触发。

  5. 替换 chat-session 装配点

    在生产 VerifyLoopOptions 装配处接入 runVerifyLoopV2，保留 v1 seam（RunVerifyFn / RunClassifierFn / VerifyConfig / TraceService），确认 ADR-0011 停止语义不变。

  6. 移除 Gate B 豁免

    原型分支专用 public-exports.test.ts Gate B costusd 豁免注释移除 / 收敛 — 恢复主干 Gate。

  7. 关闭 PR #465

    原型分支归档（keep or remove worktree 决策由 owner 出）。PR #465 不并入 master，仅作 review 痕迹。
