### Base path HIGH — incorrect for current serve

The report’s HIGH on `web/index.html` / Vite `base` assumed production assets are served under **`/web/`**.

**Current host behavior:** `iknow serve` prefers `web/dist` and serves the SPA at site root (`/`), with asset paths like `/assets/...`. That matches Vite `base: "/"`.

| Claim in report                    | Current truth                                                       |
| ---------------------------------- | ------------------------------------------------------------------- |
| Built paths need `/web/assets/...` | Dist is served at **`/`**, not under `/web/`                        |
| `base: "/"` → production 404       | Incorrect for current `resolveDefaultWebRoot` + static SPA fallback |

**Disposition:** **WONTFIX** for this pass, with reason “false positive vs current serve (dist at `/`)”. Re-open only if product intentionally moves static root to a `/web/` prefix without changing Vite `base`.
