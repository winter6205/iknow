# 0057. 阶段 2 effort 是防空转熔断，不是再试配额；形态按单次 run_graph 每 id 进入次数

Date: 2026-09-08
Status: accepted

阶段 2 的 effort 缝当真方式：保险丝，不是「业务上只准失败 N 次」。计数 = **一次 `run_graph` 调用内、每个节点 id 被进入的次数**（含首次）。默认阈值偏大，正常失败绕回不应碰到；空转应碰到。具体数字与是否进 settings 留给阶段 2 spec，本 ADR 不锁 8 还是 32。不按失败签名、不以墙钟当主闸（节点等待已有超时）。熔断后：该次调用停、已完成留下、typed 说明；之后仍可阶段 1 外环加新 id。阶段 1 仍不当闸。
