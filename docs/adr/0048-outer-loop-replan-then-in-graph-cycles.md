# 0048. 改活图走外环（阶段 1）；图内受控环是阶段 2，不是否决

Date: 2026-09-08
Status: accepted

阶段 1：一段 `run_graph` 按当时活图跑到 settle 或取消之后，用户或主代理才修订 pending（含失败后加重要试格）；已完成/失败格冻结；主代理不默认按节点事件醒来；人眼进度与模型回执分离。阶段 2：把失败/重试画进拓扑（受控环），下沉到跑图引擎。两阶段不矛盾，只排序。本 ADR 不锁修订 wire、活图生命周期、收口预算。#932。

## Why not

- **阶段 1 做图内环**：现网 `validateGraph` 拒环；无活图账本则绕回无处记账。
- **永远不做失败回环**：外环加重要试已是失败回环；否定它等于只剩一次性 DAG。
- **主代理每个节点醒来**：把管线编排放回 agent team 对话。
