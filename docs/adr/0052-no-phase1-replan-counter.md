# 0052. 阶段 1 不设专用外环次数刹车；收口靠空剩余 / 人停；活图留 effort 缝给阶段 2

Date: 2026-09-08
Status: accepted

阶段 1 不为「还能再交几段剩余子图」单独立一个会写进测试的硬顶。那样阶段 2 上图内环时要拆测试、改计数语义。阶段 1 收口 = 没有 pending（模型/用户不再交剩余子图）、用户打断或 `/reset`、以及主 loop 既有停止条件。活图上预留一条 **effort** 缝（阶段 1 恒不触发、不加验收数字）；阶段 2 的绕回圈数挂上同一条，而不是另起「外环次数」再推翻。不把 per-graph inflight 当本票收口手段。#934。

> **Amendment 2026-09-10**（ADR-0075）：阶段 1+2 host 落地后，Destination 第四句仍沿用本 ADR，不另做 host 收口停闸。#974。
