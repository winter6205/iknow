# S2 防御契约 - 详细规范

## 5 类边界 (每一类缺测 = FAIL)

| 类别 | 必须测试                  | 失败示例   |
| ---- | ------------------------- | ---------- |
| 空   | `f()` / `f("")` / `f([])` | 静默 no-op |
| 负   | `f(-1)` / `f(-MAX)`       | 假设正数   |
| 超长 | `f(<max+1> items)`        | 缓冲溢出   |
| 并发 | `Promise.all([f() x N])`  | 竞态条件   |
| 异常 | `f()` 抛预期类型          | 错误被吞   |

## 覆盖率底线

行覆盖率 >= 80% | 分支覆盖率 >= 70%

## 出处

Kent Beck 《TDD: By Example》(2002) | Robert C. Martin SOLID SRP

## AI 易违反痛点

LLM 单文件补全倾向长函数多职责, 跳过"先写最简失败测试"的节奏, 测试耦合在既有实现上而非从需求生长。
