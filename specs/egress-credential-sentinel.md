## Goal

Land ADR-0105's credential surface: HTTP(S)-family credentials (`GH_TOKEN`-style env and credential-file forms) enter the fence as **sentinel fake values** — real values never enter the fence; the host egress proxy, after TLS termination and only for **allowlisted domains ∩ entry `injectHosts`**, performs streaming headers + body one-way **fake→real** substitution. The failure direction is designed in: any missed substitution (compressed body, base64 wrapping, split by an encoder) = the fake value reaches the API as-is = authentication failure, **never real-value leakage** (ADR-0105 §Decision 3).

User story: after ADR-0104 opened the data plane, the measured incident (conversation `ee13c787`) confirmed `gh` / git push's genuine credential need inside the fence; and the "real value + allowlisted domain" combination is a complete exfiltration channel — the secret-roundtrip mask (visibility surface) guards against the model's eyes but not against code's hands inside the fence (ADR-0105 §Context). This spec installs the existence-surface defense: code inside the fence can only touch fake values, and abusing allowlisted domains still cannot carry real credentials out.

## Settled invariants

1. **Real-value existence bifurcation**: real values exist only in the host process's registry and the proxy forwarding leg; env / files / any process-visible bytes inside the fence are always fake. The only channel for `TOKEN`-style variable names into the fence is the egress env increment and the value must be a registry-minted sentinel (assembly-time assert: any injected credential-entry env value ∉ registry fake-value space → the session does not start).
2. **Substitution direction is always fake→real, and only when both gates are open**: destHost passes the filter (domain decision, 0097) ∧ matches the sentinel's entry `injectHosts` (per-sentinel gate, `credential-sentinel.js:38-43`). A missed gate always fails toward "fake value goes out = authentication failure".
3. **`injectHosts` is static**: entry lists are configuration/code constants; domains newly approved by the approval gate are **not** merged into any entry's `injectHosts` (laundering protection).
4. **The two layers coexist, neither replaces the other** (ADR-0105 §Decision 6): sentinel covers the existence surface, secret-roundtrip mask covers the visibility surface; a sentinel fake value is not a secret — it never enters recognize registration, never enters the output-mask secret set, and is not blocked by the secrets guard (the triple criterion of Assumption 14).
5. **Zero substitution on the plaintext-HTTP arm and the SSH/opaque arm**: `allowPlaintextInject` stays false; non-TLS bytes (including ssh traffic) fall into the opaque tunnel and never reach the content surface (`http-proxy.js:270-276` `:302`).
6. **Double-substitution protection**: after a body-transform replacement, continue from past the sentinel tail, real values never re-scanned (`body-substitution.js:94-115`); header substitution is a one-way split/join (`credential-sentinel.js:203`); the registry registration contract "no sentinel may be a substring of another sentinel" (`credential-sentinel.js:84-89`) is asserted by this repo's assembly layer after all registrations complete; violation = assembly failure (typed error, never start a session with partial substitution).
7. **fail-closed full coverage carries over**: session/proxy/bridge dead = no egress; CA unavailable = no mitm session started (never silently degrade to "fake values without substitution" while falsely claiming availability — degradation must leave an infra violation trace); hard-pinned client = connection failure.
8. **Zero new third-party dependencies**: mitmCA / sentinel / body-substitution are all ready-made pieces inside the pinned dependency package; node-forge is already on the load graph (ADR-0097 measured `http-proxy.js:8` ← `mitm-ca.js:10`); this spec turns "runtime-lazy" into runtime-enabled — the dependency surface does not widen and the lockfile gains no new entries (the repo rule that lockfile changes still require justification stands).
9. **`--unshare-net` always present / argv ordering discipline unchanged** (`.qoder/rules/security-boundaries.md` §Sandbox argv): the masked-file bind and trust-bundle bind land in the `egressBind` section (after workspaceMounts, before cwdReadonly, `bwrap.ts:191-196`) — last-mount-wins is the very mechanism that overlays the real path under the home ro-bind.

## Success criteria

- **SC1**: inside the fence, `echo $GH_TOKEN` yields `fake_value_…`; assembly-layer unit tests pin "real-value literal ∉ the full fence-visible surface (fence env ∪ bind table contents)"; TUI asserts the fake value on screen.
- **SC2**: inside the fence, `gh auth status` and `gh pr list` succeed (TUI pty field test, header substitution in effect); transcript evidence in the report.
