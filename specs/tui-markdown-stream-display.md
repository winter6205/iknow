# Spec: TUI markdown 围栏显示窗 + 流式块冻结

> 本 spec **不含实施代码**。下游 = `plans/tui-markdown-stream-display.md`。

## Objective

TUI 聊天里的 markdown 围栏代码块，树上只挂可见窗内的行；正在生成的那一条回复里，已经闭合的顶层块不再跟着每个新字重建。Session 全文与滚动文档里的消息条数规则不变。

成功 = 超长围栏在画面上只占窗内行数 + 溢出提示；同一条流式草稿里，前面已经写完的块在后续增量中不再重解析、不再重挂子树。

## Background

`write_file` / `edit_file` 完成态预览已有可见窗（6 行 +「还有 N 行」）。聊天正文与流式草稿里的围栏走 `Markdown` → 全量行挂载，没有同类上限。历史气泡的 memo 只挡住「别的消息」在草稿变化时重渲，挡不住「当前这条草稿每长一截就把整篇 markdown 再走一遍」。

视口挂载管的是挂哪些 **消息**；本 spec 管一条消息 **内部** 的围栏行数，以及流式草稿 **内部** 哪些顶层块可以钉住。

## Invariants

1. **Session 数据不变。** 不改 `TuiSessionState.messages`、不改 JSONL、不用 `/compact` 当 UI 裁剪。围栏截的是 OpenTUI 树上的行，不是会话正文。
2. **不是消息条数尾窗。** 禁止用「只挂最近 N 条消息」完成本 spec。滚动文档与视口挂载纪律仍以 `specs/tui-transcript-viewport.md` 为准。
3. **围栏显示窗与工具预览窗分开。** 工具完成态预览仍用既有 6 行窗，本 spec 不改那个数字。markdown 围栏可见窗固定为 **32 行**（不含溢出提示行）。超出则只挂前 32 行，并显示与工具预览同文案形态的溢出提示（`还有 N 行`，N = 未挂行数）。
4. **所有走 `Markdown` 的围栏都受显示窗约束。** 含历史 assistant 正文、流式草稿、展开态 thinking 正文。空围栏 / 不足 32 行不出现溢出提示。
5. **本轮不提供展开全文。** 溢出提示是只读折叠，不恢复行账、不做块内滚动、不挂「点开后把剩余行全部进树」。
6. **流式块冻结只针对会变长的那串 text。** 历史消息 text 引用稳定时，既有消息级 memo 仍然有效。live tail 上的草稿 / 展开 thinking：lexer 顶层块中，除 **最后一个非空块** 外全部钉住——后续增量不得再 lexer 已钉住前缀、不得再为前缀重建元素树。边界只向前推进，不回退。
7. **最后一个顶层块仍受围栏显示窗约束。** 未闭合围栏在涨：到 32 行后只更新溢出计数，不再往树上追加代码行节点。
8. **禁止行账。** 不恢复按消息估终端行数、不恢复整条消息的物理行切片路径。高度仍来自挂载后布局或与内容无关的占位。

## Never do

- 默认只 mount 最近 N 条消息。
- 把围栏显示窗改成与工具预览共用同一个 6。
- 为通过测试而丢掉会话里的代码正文。
- 改 Web markdown、session-api、harness 工具结果截断权威。
- 改 `TOOL_PREVIEW_WINDOW` 或 write/edit 完成态分类规则。
- 把 live tail 塞进视口挂载集合（tail 仍挂在消息列表之后）。

## EXIT

| 输入                           | 行为                                         |
| ------------------------------ | -------------------------------------------- |
| 围栏 0 行 / 空字符串           | 不崩；不画溢出提示                           |
| 围栏 1–32 行                   | 全挂；无溢出提示                             |
| 围栏 >32 行                    | 只挂前 32 行 + `还有 N 行`（N 为有限正整数） |
| 显示窗配置缺失 / 非正 / 非有限 | 退回 32；不把会话渲成空白                    |
| 流式 text 非字符串             | 抛 typed `TypeError`                         |
| 流式只有一个顶层块             | 无前缀可钉；该块仍受显示窗约束               |
| 两次冻结计算交错               | 互不影响（无共享可变边界）                   |

## Testing strategy

显示窗纯函数覆盖 5 类边界：empty、negative（非法窗宽退回 32）、overflow（远超 32 行只产出窗内行 + N）、concurrent（两次调用互不影响）、exception（由调用方保证的非字符串 → `TypeError`，若纯函数收 `unknown`）。

流式冻结纯函数覆盖：empty；只有一块（前缀空）；多块且最后一块变长（前缀 raw 稳定、边界单调增）；前缀在后续调用不得变短。

`Markdown` / ChatView 集成：历史围栏超 32 行画面含溢出提示、不含第 33 行正文；流式草稿先闭合一块再增长下一块时，第一块的 lexer 次数在后续增量中为 0（或等价：前缀子树不因后缀变长而重解析）。既有工具预览 6 行测不倒退。

## Out of scope

- 视口挂载算法、`FULL_MOUNT` 阈值、滚动量化。
- 围栏点开展开、块内独立 scrollbox。
- 把围栏改成另一种底层文本缓冲实现。
- Web、compact、工具预览窗数字。
